## 🎯 Topics Covered

### Capacity Planning & Forecasting
- Forecasting methods: ARIMA, Prophet, Holt-Winters, XGBoost, neural networks
- Optimization: Linear programming, mixed-integer programming, bin packing
- Decision support systems: dashboards, what-if simulators, alerting

### Data Platforms & Analytics Pipelines
- Data platform architecture: ingestion → storage → processing → serving
- Batch vs streaming (Spark, Flink, Kafka), ETL vs ELT, dbt
- Data lake vs data warehouse vs lakehouse
- Data quality, lineage, and governance

### ML/AI Systems & MLOps
- Feature stores, model serving patterns, A/B testing
- ML lifecycle: train → validate → deploy → monitor → retrain
- Model drift detection (data drift, concept drift)

### AI-Assisted Engineering
- LLMs in engineering workflows (code, incidents, capacity planning)
- AIOps: anomaly detection, incident prediction, auto-remediation
- RAG for decision support (grounding LLMs in internal knowledge)
- Human-in-the-loop patterns and guardrails
