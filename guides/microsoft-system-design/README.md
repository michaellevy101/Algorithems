## 📖 Guide Structure

Each guide follows a consistent format:

1. **Problem Statement** - What you're designing
2. **Clarifying Questions** - Questions to ask the interviewer
3. **High-Level Design** - ASCII architecture diagram
4. **Key Components** - Table of components and technologies
5. **Scalability Considerations** - How to scale
6. **Trade-offs** - Design decisions with pros/cons
7. **How to Explain It Well** - Interview talking points
