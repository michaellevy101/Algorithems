## 🎯 Study Paths

### Beginner (2-3 weeks)
1. Binary Search → Two Pointers → Sliding Window
2. Basic Graph (BFS/DFS) → Tree Traversals
3. Simple DP → Backtracking basics

### Intermediate (3-4 weeks)
1. Union-Find → Monotonic Stack → Intervals
2. Heaps → Greedy Algorithms
3. Advanced DP → String Algorithms

### Advanced (4-6 weeks)
1. Complete Graph (Dijkstra, MST)
2. Complex DP → Advanced Backtracking
3. String matching → Flow Algorithms
